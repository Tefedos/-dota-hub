Обозначения: S=survival, P=participation, E=economy, I=impact; `—`=отсутствующая ось. Base — `100 × Σ(weight × axis) / coverage` **до** credit. Итог `round_half_up(max(0, base-credit))` рассчитывается только при минимум двух осях и coverage≥0,7.
