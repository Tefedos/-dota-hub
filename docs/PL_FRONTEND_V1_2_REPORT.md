# PL v1.2 — Frontend вкладки «Игроки»

**Статус: READY FOR QA.** Независимая пользовательская приёмка и проверка в Telegram Mini App ещё не выполнены.

## Аудит

До доработки `PlayersSection` уже группировал участников по командам, показывал K/D/A, часть статистики и портреты из локального справочника. `MatchReportPage` уже получал секцию одним запросом через общий API-клиент и показывал loading/error/limitations. Активная вкладка и горизонтальный скролл навигации уже работали. Мастер-план v0.1 содержит задачи PL-01–PL-08; внешний файл мастер-плана не изменён.

Фактический Backend DTO отличается от примерного типа в промпте: `hero_id` и элементы инвентаря допускают `null`, неизвестный предмет имеет статус `unmapped`, а не `unknown`. Frontend учитывает оба варианта статуса без подмены данных.

## Ограничения и статус мастер-плана

Backend не предоставляет подтверждённые игровые позиции для всех участников и не всегда предоставляет wards, stun duration и buyback count без парсинга. Frontend не выводит вымышленные роли и не создаёт пустые карточки для отсутствующих дополнительных метрик. Сведения об ограничениях остаются в общем блоке страницы.

Предлагается перевести PL-01–PL-08 и PL-FE-00–PL-FE-08 в **READY FOR QA**, после независимой проверки функциональности и мобильного Telegram WebView. `PL-FE-09` упомянута в шапке промпта, но отдельное требование для неё не описано; статус ей не присваивался. В **DONE** задачи не переводились.

Запуск локально: из корня проекта `.venv/bin/python scripts/local_postgres.py start`; в `backend/` — `DOTA_LOCAL_ALPHA=true ../.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`; в `frontend/` — `npm run dev -- --host 127.0.0.1 --port 5173`. Для проверки сохранённых матчей повторный запрос OpenDota не нужен.
