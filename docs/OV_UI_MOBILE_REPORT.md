# Dota Hub — OV-UI, корректировка мобильного «Обзора»

**Статус: READY FOR QA.** API, backend, аналитика и маршруты не менялись. Коммит не создан.

Изменены `frontend/src/pages/MatchReportPage.tsx`, `frontend/src/features/matches/OverviewSection.tsx`, `frontend/src/shared/ui/styles.css`, `frontend/src/features/matches/OverviewSection.test.tsx`. Добавлены этот отчёт и снимки в `docs/qa/overview_ui_screenshots/`.

Верхние вкладки остались прежними кнопками и логикой переключения. Теперь они занимают одну строку и прокручиваются горизонтально; после выбора крайняя активная вкладка автоматически остаётся видимой. Убраны повтор Match ID в Overview и дублированные названия команд в результате. Результат стал ниже: имя каждой команды показано один раз, победитель выделяется по `winner` без вложенной рамки. Статус сокращён до «Готов · Есть ограничения». В статистике `null` показан как «—» отдельно у Radiant и Dire; короткое пояснение находится под таблицей. Карточки игроков только слегка уплотнены на mobile. Составы, портреты, fallback, порядок и раскрывающиеся ограничения сохранены.
